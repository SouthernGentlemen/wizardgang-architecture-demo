## Known limitations

- Public assurance data is a disclosure-safe projection, not the complete private operational, forensic, treatment, vulnerability-report, or acceptance record.
- Repository evidence resolves only against the exact deployed commit identified by `DEPLOYED_SHA`; no moving-branch fallback is used when deployment identity is unavailable.
- The published-advisory dataset may legitimately be empty. An empty dataset does not claim that no vulnerabilities, private reports, defects, or security investigations have existed.
- Publishing a security advisory never creates or implies an incident record, and CVE linkage is recorded only after a real identifier is assigned.
- ISO/IEC 27001, ISO/IEC 42001, WCAG, and related statements remain alignment claims only; certification is not claimed.
