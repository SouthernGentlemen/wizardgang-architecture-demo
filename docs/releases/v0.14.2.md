# WizardGang Architecture Demo v0.14.2

**Product:** WizardGang Architecture Demo

**Version:** v0.14.2

**Release date:** 2026-09-07

**Commit:** the commit this tag names — `git rev-list -n1 v0.14.2`

## Scope

Enforce a main-only repository branch policy by removing the automated `assurance-reports` branch publisher and its duplicate retained-report source shape. The canonical `reports` collection now presents GitHub's provider-native workflow attempts through the existing reporting query, pagination, authorization, availability, and presentation layers.

The application route inventory remains unchanged at eight HTML pathnames and 61 declarative routes. No removed URL, redirect, alias, proxy, dual endpoint, or client fallback is restored.

## Included changes

- [DEMO-190] [CHORE] Remove the branch-backed report publisher, retained-report generator, special provider reader, standalone report schema, branch-specific tests, and current documentation/configuration references.
- Bind reporting domain `reports` to the registered `github.workflow-attempts` native source. Workflow runs, attempts, artifacts, commits, tags, releases, and relationships remain queryable through `/api/reporting` and the one canonical reporting schema.
- Add regression coverage proving the registry and schema have no retained-report declaration and the branch publisher, generator, and duplicate schema do not exist.
- Preserve the protected GitHub-source authorization boundary and disclosure-safe anonymous behavior.
- Align `package.json` and `package-lock.json` with patch version 0.14.2.

## Known limitations

- GitHub controls native workflow-run, attempt, job, log, and artifact retention. The application reports provider expiration and availability instead of copying provider state to a second Git branch.
- Anonymous GitHub provider queries remain explicitly unavailable when provider authentication is required; protected sources require an authorized operator and configured read credentials.
- Removed page and API families intentionally return the ordinary 404 and have no compatibility route.
- Public assurance data remains a disclosure-safe projection and does not claim ISO/IEC or WCAG certification or formal conformance.
