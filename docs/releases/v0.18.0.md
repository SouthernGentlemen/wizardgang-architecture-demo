# WizardGang Architecture Demo v0.18.0

**Product:** WizardGang Architecture Demo

**Version:** v0.18.0

**Release date:** 2026-09-09

**Commit:** the commit this tag names — `git rev-list -n1 v0.18.0`

## Scope

Release the completed site-wide accessibility and internationalization stack after its runtime, localization, remediation, assurance, and browser-verification changes were merged in dependency order.

## Included changes

- DEMO-235: promote locale resolution, language direction, shared accessibility behavior, and locale persistence into the global application runtime.
- DEMO-236: localize public presentation across `en`, `es`, `fr`, `de`, `ja`, and `ar` through one shared catalog and request boundary.
- DEMO-237: remediate shared WCAG 2.2 engineering gaps, replace the embedded GraphiQL interaction, and complete accessible OpenAPI and teaching-surface behavior.
- DEMO-238: add canonical route-derived accessibility/i18n gates, deterministic critical-state coverage, local Chromium/axe auditing, conservative assurance evidence, and a structured pending manual-verification matrix.

## Validation

The release candidate passed the complete repository check with 549 tests across 93 test files, local migrations, the dependency audit with zero vulnerabilities, the Worker dry-run build, and `git diff --check`. Dedicated gates passed 4 deterministic site-accessibility assertions, 3 deterministic site-localization assertions, and 20 focused accessibility tests. The local Chromium audit passed 31 canonical public routes, 62 route/locale renders, 5 explicit state fixtures, 78 axe runs, 4 narrow-reflow samples, and 4 keyboard-smoke samples.

The automated result is limited to no automatically detectable violation observed in the bounded matrix. It does not establish WCAG 2.2 or Level AAA conformance.

## Deployment

Target: `demo.wizardgang.ai`. The tag-triggered Release workflow reproduces the annotated v0.18.0 state, publishes a release-bound assurance snapshot, deploys the exact tag, and verifies public version/commit identity and Worker health.

## Known limitations

- The structured manual accessibility matrix remains pending; no reviewer, date, pass, or evidence is recorded for procedures that have not been manually performed.
- Named screen-reader review, complete keyboard traversal, 400% zoom and text-spacing review, rendered contrast interpretation, human RTL review, target-size exception review, announcement quality, and authenticated-state review remain manual work.
- Automated axe and browser checks cover only machine-detectable behavior in the configured route/state matrix and are not certification.
