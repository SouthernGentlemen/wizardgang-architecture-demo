# WizardGang Architecture Demo v0.15.0

**Product:** WizardGang Architecture Demo

**Version:** v0.15.0

**Release date:** 2026-09-08

**Commit:** the commit this tag names — `git rev-list -n1 v0.15.0`

## Scope

Release the canonical frontend resource hierarchy delivered by DEMO-191 through DEMO-198 while preserving the generic router, declarative application registry, capability-owned route declarations, generated route documentation and manifest, and every API and protocol contract.

The generated registry now produces 85 declarative routes and 32 page declarations. Of those pages, 30 public canonical HTTPS URLs are projected into the sitemap; `/admin` remains private and `/offline` remains the non-indexed recovery page. These counts are observed outcomes of the merged declarations, not fixed targets or encoded architecture invariants.

The public canonical hierarchy is:

- `/`
- `/platform` and `/platform/{edge,workers,durable-objects,d1,r2}`
- `/interfaces` and `/interfaces/{rest,graphql,webhooks,identity,mcp,i18n,accessibility}`
- `/assurance` and `/assurance/{delivery,governance,evidence,compliance,risks,incidents,concerns}`
- `/security`
- `/operations` and `/operations/{availability,logs,usage,reports,docs}`

`/platform?view=d1` and every other retired `?view=` URL now return the ordinary 404 with no `Location` header. No redirect or compatibility route is provided, so this release intentionally breaks bookmarks to the retired query-selected views. Retired pathnames remain dead as well, including `/edge`, `/d1`, `/api`, `/compliance`, `/evidence`, `/governance/*`, `/dashboard/*`, `/graphql/console`, `/v1/*`, and `/__api/*`.

Assurance record fragments remain stable on their new canonical bases. Examples include `/assurance/risks#SEC-RISK-001`, `/assurance/risks#AI-RISK-001`, `/assurance/incidents#EX-001`, `/assurance/evidence#EVD-SRC-001`, and `/security#ADV-*` when a disclosure-safe advisory record exists. The incident and advisory collections are intentionally empty at release time, so no fictional `INC-*` or `ADV-*` anchor is claimed.

## Known limitations

- Bookmarks to retired query-selected views and removed page families break intentionally. They receive the ordinary 404 with no redirect or `Location` header.
- The public incident and advisory datasets are empty at this release. `/assurance/incidents` still presents the retained `EX-001` exercise anchor, while no `INC-*` or `ADV-*` record or anchor is fabricated.
- Public assurance data is a disclosure-safe projection and does not claim ISO/IEC certification, WCAG conformance, complete incident absence, or complete vulnerability absence.
- Identity-provider redirect verification proves the configured authorization-start boundary; it does not complete a third-party sign-in or assert provider availability beyond the observed redirect.
- Rolling back to v0.14.2 restores the query-selected eight-page frontend contract and therefore reverses the bookmark-breaking hierarchy change.
